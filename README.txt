MAAZSTAAR WORLD - DATA SELLING WEBSITE

Files:
- index.html
- services.html
- contact.html
- style.css
- script.js
- logo.jpg
- netlify.toml
- 404.html

NETLIFY:
1. Upload this whole folder (or the ZIP) to Netlify.
2. No build command is required.
3. Publish directory: .
4. The site is a normal static multi-page website.

GITHUB PAGES:
1. Create a repository.
2. Upload all files from this folder to the repository root.
3. Go to Settings > Pages.
4. Choose Deploy from a branch.
5. Select the main branch and root folder (/).
6. Save.

HOSTING / CPANEL:
Upload all files into public_html. Keep all files in the same folder.

IMPORTANT:
Do not upload only index.html. Upload the complete folder so the Services,
Contact, CSS, JavaScript, logo, Netlify config and 404 page are included.
